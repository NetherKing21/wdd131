Dice Roll Project Plan

Brayden McAllister

WDD 131

Overview

Purpose

A cite for easy dice rolling for board games and common TTRPGs.

Audience

The target audience is all game enjoyers. Young to old, male and female.

Dynamic elements

Dynamic elements include:

  • rolling different amount and size of dice based on user input and displaying the total
  • closable instructions section that explains how the page works
  • be able to add more dice (maybe roll all of them at once)

Pseudocode for your project

Dice roll logic

  1. Get value of dice number and dice size from input
  2. generate random numbers equal to the number of dice between 1 and the dice size
  3. Add the numbers together and display the total (and maybe the individual rolls)

New Dice Logic

  1. When add dice button is clicked
  2. Add dice card template to the bottom and generate event listeners
